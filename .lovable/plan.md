## Daily Stoic Mini Crossword

A 5x5 mini crossword themed on Stoicism, refreshed daily, with progress saved in the browser.

### Scope

- Size: **5x5 mini** (~6–8 clues, 2–4 minute solve). Small enough that I can hand-curate a deep pool and the grid stays elegant on the modern UI.
- Source: **hand-curated pool** of ~30 pre-built puzzles (no AI, no runtime cost). Daily selection is deterministic from UTC date, same pattern as the existing daily quote (`pickDaily` in `routes/index.tsx`).
- Progress: stored in `localStorage`, matching the existing `src/lib/history.ts` pattern.

### New files

- `src/data/crosswords.ts` — `Puzzle` type + `PUZZLES` array. Each puzzle has:
  - `id` (e.g. `mini-001`)
  - `grid`: 5×5 array of `string | null` (null = black square)
  - `clues`: `{ across: {num, clue, answer}[]; down: {num, clue, answer}[] }`
  - `note`: optional one-line Stoic context shown after solving (e.g. "LOGOS — the rational order Marcus calls 'the ruling reason'.")
  - Helper `pickDailyPuzzle()` mirroring the daily-quote selector.
  - Initial batch: ~30 puzzles seeded with Stoic vocabulary (LOGOS, AMOR, FATI, VIRTU, ETHOS, ZENO, CATO, APATHEIA shortened, etc.), philosopher names, and themes already in the data.
- `src/lib/crossword-progress.ts` — load/save per-puzzle state keyed by puzzle id: `{ cells: string[][]; completedAt?: number; revealed?: boolean }`. Includes `clearProgress(id)`.
- `src/components/CrosswordGrid.tsx` — controlled 5×5 grid:
  - Keyboard navigation (arrows, tab between clues, backspace moves back, auto-advance).
  - Click/tap a cell to focus; click again to toggle across/down direction.
  - Highlights current cell + current word; numbers in top-left of starting cells.
  - "Check", "Reveal letter", "Reveal puzzle", "Clear" actions.
  - Emits `onSolve` when grid matches answers; persists state on every change.
- `src/components/CrosswordClues.tsx` — Across/Down lists, current clue highlighted, click to jump.
- `src/routes/crossword.tsx` — `/crossword` page:
  - Renders today's puzzle with header, date, grid, clues, and a sticky mobile clue bar showing the active clue.
  - On solve: confetti-free congratulations card with the puzzle's Stoic note, a "Share" button (reuses `ShareQuote` pattern — text only, no quote schema), and a link back to `/ask`.
  - SEO `head()` with title "Daily Stoic Crossword — The Stoic Reference" and description.

### Design

Matches existing aesthetic (Instrument Serif headlines, Inter body, off-white bg, cobalt accent, `shadow-soft` cards). Grid uses:
- White cells with 1px `border-border`, black cells with `bg-foreground`.
- Active cell: `bg-accent/15`, current word: `bg-accent/5`.
- Cell font: Inter, uppercase, tracking-wide; clue numbers in `text-[10px]` top-left.
- Mobile: grid scales to viewport width with `aspect-square`, clues stack below; on desktop, grid left / clues right in a 2-col layout.

### Out of scope

- AI-generated puzzles (declined).
- Cross-device sync / accounts.
- Larger (midi/full) crosswords — can extend the `Puzzle` type later; grid component is size-agnostic.
- Leaderboards or solve timers (no timer shown; just a "solved" check mark per day in history).
