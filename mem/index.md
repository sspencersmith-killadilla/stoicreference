# Project Memory

## Core

Identity: "Paper & Ink" — warm letterpress paper (#F5F3EE) + ink (#2D2D2D) + ink-strong (#0D0D0D) + hairline border (#E8E4DD). No chromatic accent; no gradients.
Type: Libre Baskerville (display/italic) + IBM Plex Sans (body, small-caps uppercase 0.22em tracking).
Surfaces: 1px hairline borders only. No shadows, no rounded corners, no card lift. `shadow-soft`/`shadow-pop`/`aurora-bg` are retired no-ops; do not reintroduce.
Structural glyph: `✻` (U+273B) faint top-left on quote specimens — the one repeating identity mark.
Puzzle tray (`bg-ink`) is the single tonal counterpoint (cream-on-black).
